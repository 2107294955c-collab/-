# Week 13 AI Chat Log

## Round 1

**Question:** 四足机器人和轮式机器人相比，主要区别是什么？  
**Answer:** 轮式机器人适合平坦地面，控制相对简单；四足机器人适合复杂地形，但需要协调四条腿、身体姿态和支撑稳定性。

## Round 2

**Question:** 什么是 Trot 步态？  
**Answer:** Trot 是四足机器人常见步态，特点是对角腿成组运动，例如 LF 和 RH 一组，RF 和 LH 一组，两组交替支撑和摆动。

## Round 3

**Question:** 本周的 Python 脚本应该体现什么内容？  
**Answer:** 脚本至少要体现四条腿的命名、步态分组和每一步支撑/摆动状态，让代码能够说明四足机器人运动逻辑。

## Round 4

**Question:** week13 README 应该补充哪些评分点？  
**Answer:** 应该包含实验目标、文件结构、理论整理、运行命令、截图、问题解决和学习总结，同时补充反思文件和 AI 协作记录。

## Round 5

**Question:** week14 项目前需要做哪些准备？  
**Answer:** 需要准备手机遥控网页、Python 控制服务器、迷宫配置、自动探索逻辑、截图证据和 PDF 报告，并保证文件名和目录符合评分规范。

## Round 6

**Question:** 如何让作业更容易被自动评分系统识别？  
**Answer:** 使用规范目录名，提交清晰 README，放入实际图片和代码文件，避免乱码和断链，并在 README 中明确引用截图、运行命令和总结。
